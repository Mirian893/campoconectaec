# 🌱 CampoConectaEc

**Conectando productores agrícolas con compradores.**

# 📌 Descripción del proyecto

CampoConectaEc es una plataforma web orientada a conectar pequeños productores agrícolas con personas y negocios interesados en adquirir sus productos.

Su propósito es facilitar la comercialización directa, mejorar la visibilidad de los productores y brindar a los compradores herramientas para encontrar productos agrícolas según sus necesidades.

# 🎯 Objetivo

Desarrollar una plataforma digital que facilite el encuentro entre pequeños agricultores y compradores, promoviendo oportunidades de comercialización y relaciones comerciales más accesibles y transparentes.

# 👥 Usuarios de la plataforma

# Productores agrícolas

- Registrarse y crear un perfil.
- Publicar productos agrícolas.
- Indicar precios, cantidades y ubicación.
- Actualizar la disponibilidad de sus productos.

# Compradores

- Explorar productos agrícolas.
- Buscar por nombre o categoría.
- Filtrar por precio y ubicación.
- Consultar información de los productores.
- Contactar directamente con los vendedores.

# 🛠️ Tecnologías previstas

- Python

- SQLite
- Git

# 🚀 Estado del proyecto

**En desarrollo.**

Actualmente se encuentra en la etapa de planificación y preparación del entorno de desarrollo.

# 🗺️ Alcance inicial

La primera versión buscará implementar el registro de usuarios, la publicación de productos agrícolas, un catálogo de productos y filtros de búsqueda.

# 🌎 Proyección

CampoConectaEc busca convertirse en una herramienta digital que contribuya a fortalecer la comercialización de pequeños productores, comenzando con un enfoque local en Chimborazo, Ecuador.
